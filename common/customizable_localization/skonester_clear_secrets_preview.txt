# 互动说明：有秘密时留空；无任何将被清除的秘密时显示一行提示（避免整段空白）
skonester_clr_any_secrets_hint = {
  type = character
  random_valid = no
  text = {
    trigger = {
      OR = {
        any_secret = { always = yes }
        any_targeting_secret = { always = yes }
        any_known_secret = { always = yes }
      }
    }
    localization_key = skonester_zw_empty_loc
  }
  text = {
    trigger = { always = yes }
    localization_key = skonester_clear_secrets_no_secrets_hint_loc
    fallback = yes
  }
}
